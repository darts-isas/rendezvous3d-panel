# Changelog

## 1.0.0 (Unreleased)

Initial release.

### Added
- `Brightness` option on Sphere and 3D Model objects, settable as a fixed value or bound to a data source field (clamped to 0-1). Darkens the object's color under the same lighting without affecting opacity/transparency.

### Changed
- Plugin id/name prefix renamed from `isasjaxa-` to `dartsisas-` (`dartsisas-rendezvous3d-panel`). Update provisioning dashboards, docker compose, and documentation accordingly.
